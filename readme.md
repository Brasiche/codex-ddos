# codex-ddos

Les attaques DDoS (Déni de Service Distribué) sont une forme d'attaque par déni de service (DoS). Une attaque DDoS utilise plusieurs appareils connectés à internet qui agissent ensemble pour submerger une cible.

Comment installer codex-ddos

L'installation est très simple. Ouvrez votre terminal et tapez les commandes suivantes !


## Mise à jour du système

```
$ apt update && apt upgrade
```

## Installation des dépendances

```
$ apt get install python3
```
``` 
$ apt get install git
```
```
$ apt get install figlet
```

## Cloner le projet

```
$ git clone https://github.com/Brasiche/codex-ddos.git
```

## Se déplacer dans le dossier

```
$ cd codex-ddos
```

## Rendre le script exécutable

```
$ chmod +x codex-ddos.py
```

## Lancer le script

```
$ python3 codex-ddos.py
```

L'installation de votre outil est terminée !

## Pour tester votre propre serveur, utilisez une de ces méthodes :

• Tapez ifconfig ou ip a pour trouver l'IP de votre machine locale

• Ou utilisez curl ifconfig.me pour connaître votre IP publique

Une fois l'IP de votre serveur obtenue, revenez dans la Console. Collez l'IP sur IP Cible : et entrez le port sur lequel tourne votre service (ex: 80, 443, 8080).

⚠️  Attention : Testez uniquement sur vos propres serveurs ou avec une autorisation écrite. Toute attaque contre un serveur tiers est illégale.
